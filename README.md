# 📊 Retail Transaction Dashboard

## 📌 Project Overview

This project presents a comprehensive **Retail Transaction Dashboard** built using Power BI to analyze sales performance, customer behavior, and pricing strategies.

The dashboard provides actionable insights into how different factors such as product categories, payment methods, discounts, and geographic locations impact overall business performance.

## 🎯 Objective

The goal of this project is to:

* Analyze retail sales trends over time
* Understand customer purchasing behavior
* Evaluate the impact of discounts on sales
* Identify top-performing product categories and regions
* Support data-driven decision-making
  
## 📂 Dataset Description

The dataset includes transactional-level retail data with the following key fields:

* CustomerID
* ProductID
* ProductCategory
* Quantity
* Price
* TransactionDate
* PaymentMethod
* StoreLocation
* DiscountApplied (%)
* TotalAmount

## 📊 Dashboard Features

### 📈 Sales Analysis

* Monthly sales trend to identify seasonality and performance patterns
* Consistent sales distribution across months with minor fluctuations
  
### 🛍️ Product Category Insights

* Sales distribution across categories such as Books, Clothing, Electronics, and Home Decor
* Balanced contribution from all categories (~25% each)
  
### 💳 Payment Method Analysis

* Comparison of payment methods (PayPal, Cash, Credit Card, Debit Card)
* Nearly equal usage across all payment types
  
### 🗺️ Geographic Analysis

* Sales distribution across different states using a filled map
* Identifies high-performing regions contributing to revenue

### 💸 Discount Impact Analysis

* Average sales analyzed across discount ranges (0–5%, 5–10%, 10–15%, 15–20%)
* Insight: Higher discounts do not significantly increase average order value.
  
## 🎛️ Filters (Interactive)

The dashboard includes interactive filters for:

* Quarter
* Product Category
* Payment Method

These filters dynamically update all visuals, enabling deeper analysis.

## 🛠️ Tools & Technologies

* Power BI (Data Visualization & Dashboarding)
* DAX (Data Analysis Expressions)
* Data Cleaning & Transformation

## 🧠 Key Insights

* Sales remain relatively stable across months, indicating consistent demand
* Product categories contribute almost equally to total revenue
* Discounting does not strongly impact average transaction value
* Payment preferences are evenly distributed across methods
* Certain states contribute more significantly to total sales
